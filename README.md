## 🙌 Acknowledgement

First of all, I would like to express my deep gratitude to the original author of [**Read You**](https://github.com/ReadYouApp/ReadYou) and all the contributors who have put their time and effort into building such a wonderful open-source RSS reader.

Without their hard work, **RSS Hub** would never have been possible.  
This fork aims to continue that spirit — maintaining, improving, and adapting the app for modern Android devices, while keeping it free and open for everyone.

---

## 🚀 About RSS Hub

**RSS Hub** is a fork of [Read You](https://github.com/ReadYouApp/ReadYou).  
It inherits the clean Material You design and powerful RSS reading features, while introducing new fixes and enhancements.

### 🔧 Key Improvements in RSS Hub
- ✅ Fixed numerous **bugs** for a smoother user experience
- 🎨 Updated **styles** for improved Material You consistency
- 📱 Added **support for the latest Android versions**
- 🛡️ Fixed **memory leaks** detected by LeakCanary
- ⚡ Performance and stability improvements

---

## ✨ Features

- Subscribe to RSS links
- Import/export OPML files
- Notifications for new articles
- Optimized article readability
- Full content parsing for original articles
- Multi-account support
- Read aloud articles

*(Future updates will bring more exciting features!)*

## 🛠️ Build from Source

RSS Hub is built with [Jetpack Compose](https://developer.android.com/jetpack/compose).

1. Clone the repository:
   ```bash
   git clone https://github.com/loitran247/RSSHub.git

2. Then open it via [Android Studio (latest version)](https://developer.android.com/studio).

3. When you click the `▶ Run` button, it will be built and run automatically.

   > In case of lag, please select Release version build.
